# Meeting-MGR

A self-hosted meeting records keeper. Audio/video goes in, complete meeting
minutes come out. See `plans/project_vision.md`.

## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues on `sgtslaughta/meeting-mgr`, managed with
the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary; label strings match the role names. See
`docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See
`docs/agents/domain.md`.
